Find local businesses with no website or an outdated one, then export them to CSV. Uses free OpenStreetMap data: no API key, no billing.

Browsers block reading most websites directly, so website visits go through the proxy. Public proxies are unreliable; for steady use, host your own (a Cloudflare Worker works) and paste its URL here.

Post codes work best in countries that use them (India PIN codes, UK, US ZIP and so on). The UAE has no post code system, so use a city or area such as Dubai Marina. OpenStreetMap is volunteer-edited. A business showing "No website" may simply be missing that detail, so use the Google link in each row to double-check before you reach out.
